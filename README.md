# doc-reorg-skill

语雀知识库文档整理 Skill：**随看随搬、零格式转换、人工终审闸**。

## 解决什么

把源知识库（A 库）里的有用文档筛选搬运到目标知识库（B 库），
适用于文档量大、无法先列清单再审的场景。

## 核心设计

1. **随看随搬** — 文档量大时不做"先列清单再审"，AI 边扫边判边搬
2. **搬运与格式解耦** — 搬运阶段只判"有用性"原样搬，格式统一（如有）单独一轮做
3. **零格式转换** — 源文档是什么格式（lake / markdown / sheet）就写什么，不转换
4. **人工终审闸** — AI 自查 ≠ 过审，终审通过前禁入库禁发布

## 使用

Skill 内容见 `SKILL.md`，判定规则细则见 `references/rules.md`。

```mermaid
flowchart TD
    A[取一篇A库文档] --> B{正文是二进制?}
    B -- 是 --> X[不搬]
    B -- 否 --> C{是数据库dump?}
    C -- 是 --> X
    C -- 否 --> D{属于有用范围?}
    D -- 是 --> E[原样搬进B库<br/>保留 format 原值<br/>零转换]
    D -- 否 --> X
    E --> F[记录搬运日志]
```

## 规则速览

| 规则 | 判定 |
|---|---|
| R1 正文二进制 | 正文无法解析 → 不搬 |
| R2 数据库 dump | 不搬 |
| R3 附件 | 正文是文字的，附件照搬 |
| R4 格式 | 源格式是什么就写什么，零转换 |
| R5 有用性 | 老板给定范围（范围法/目录法/全扫法） |
