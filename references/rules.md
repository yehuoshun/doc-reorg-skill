# 判定规则详表

## 规则来源

本文档为 `doc-reorg` Skill 的判定规则细则，对应 SKILL.md 中的 R1–R5。

## R1 正文二进制 → 不搬

- 判定方式：文档正文无法解析成文本（二进制内容）
- 注意：纯附件文档（正文是文字、挂附件）**要搬**，附件跟着正文走
- 一句话：看正文，不看附件

## R2 数据库 dump → 不搬

- 判定方式：文档内容是数据库 dump
- 优先级：R1 > R2 > R3 > R4 > R5，顺序判定，命中即止

## R3 附件 → 随正文搬

- 正文是文字的文档，其附件一并搬运
- 附件不独立成篇，跟随所属文档

## R4 格式零转换

- 源文档 `format` 字段的取值：`lake` / `markdown` / `sheet`
- 搬运时 `yuque_copy_doc` 的 `format` 参数传源文档 format 原值
- 不做 lake→markdown 之类的转换（会丢代码块、图片、表格格式）

## R5 有用性范围（老板给定）

三种填法，任务开始时向老板确认：

| 方式 | 说明 | 特点 |
|---|---|---|
| 范围法 | 给主题/关键词清单，命中才搬 | 最严，AI 不会搬错 |
| 目录法 | A 库指定目录整片搬，其他跳过 | 最省事，不用逐篇判断 |
| 全扫法 | A 库全扫，能解析的文本都搬 | 最宽，可能搬进垃圾 |

## 拿不准处理

- R5 命中不了硬规则 → 打标"拿不准"，集中列一行给老板扫一眼，不搬
- 不猜，不自行扩大/缩小范围
